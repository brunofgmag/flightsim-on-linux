FSS Boeing 727-200

Tested with the FSS Boeing 727-200 1.1.7 on 15 October 2026. Nothing Linux-specific is needed beyond the store it comes from: the aircraft is a set of MSFS packages that runs inside the simulator.

Get it

The 727 comes from the Aerosoft One store, as the packages fss-aircraft-boeing-727-200f (the freighter) and fss-aircraft-boeing-727-200re. This guide doesn't have the store page or the price, so look in the store. addon install fss-727 only prints where it comes from.

Install it

Install the aircraft with Aerosoft One, as on Windows. Its guide covers the app itself, which is a native Linux program that needs two options on its command line and has to be pointed at the simulator's packages folder. On 14 October 2026 Aerosoft One installed the aircraft into its own library on the test machine and made links to it in the Community folder.

~/flightsim-on-linux/bin/flightsim-on-linux addon install fss-727

That command prints the store and the kind of installer, and runs nothing.

Make it run

Nothing. The aircraft needs no Proton FS2024 patch and no setting in the prefix. It was tested on Proton FS2024, and stock Proton was not tried. addon apply fss-727 says there is nothing to apply and then runs the check.

Check it

~/flightsim-on-linux/bin/flightsim-on-linux addon check fss-727

It prints one line for each of the two packages that is in your Community folder, starting with ok and giving the version, and it changes nothing. A link that resolves counts, because that is how Aerosoft One installs. It prints FAIL when neither package is there, when a package is a link to a folder that is gone, or when a package has no readable manifest.json.

Known problems

  • Moving the Aerosoft One library removes the aircraft, because the links in Community point into the old place. The check then reports a link to a folder that is gone. Keep the library where Aerosoft One put it.
  • On 15 October 2026 both freighters flew on the test machine and activated on their first load. The passenger version, the 200REP, was not seen.

Undo

addon undo fss-727 has nothing to restore, because nothing was changed. Remove the aircraft with Aerosoft One.
