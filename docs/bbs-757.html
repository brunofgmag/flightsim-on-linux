BlueBird Simulations 757-200

Tested with the 757-200 0.1.0 and its liveries 1.0.0. The test machine flew Heathrow to Keflavik on 27 October 2026, and the systems and the terrain on the navigation display worked on 28 October. The aircraft needs nothing in the prefix. BBS Nest is the hard part, and it has its own page.

Get it

The aircraft comes from your BlueBird Simulations account, and BBS Nest installs it. There is no separate installer for the aircraft. This page doesn't have the account's address. Nest installs two packages in your Community folder: bluebirdsim-aircraft-757-200 and bluebirdsim-aircraft-757-200-liveries.

Install it

  1. Install Nest, following the Nest page: addon install bbs-nest, with the simulator and every other program of the prefix closed.
  2. Open Nest alone, with the simulator closed and nothing else in the prefix (addon launch bbs-nest), and let it install the aircraft. On the test machine it installed both packages on 24 October 2026, and the sizes in each package's layout.json matched the files on disk.
  3. Check that Nest's Settings folder is your real Community folder. On the test machine Nest had stored another folder, Community2024, and showed the aircraft as NOT INSTALLED. Change it in Nest's Settings and open Nest again. The check below reads that value.

Nest is a program of the prefix, so the ground rule applies: run it alone when you install or update, never next to another installer.

Make it run

~/flightsim-on-linux/bin/flightsim-on-linux addon apply bbs-757

This changes nothing and runs the check. The aircraft's own needs are met somewhere else:

  • Nest open beside the simulator. Without it the EFB shows BBS|NEST is not running. Please start BBS|NEST to run the aircraft systems. and the systems stay off. Open it from the menu entry of the Nest page, with the simulator running.
  • Terrain on the navigation display. Nest draws it from files relative to its own folder, so it has to be started the way the launch script does, with start /d. The Nest page has the details.
  • The pacing patch in Proton FS2024. It took Nest from 21.3% to 11.3% of the GPU's streaming multiprocessors on the test machine. addon check bbs-nest proves it is in your build.

Start it

There is nothing to start for the aircraft. Open Nest, as above, and load the 757 in the simulator. Open Nest after the 757 is loaded: if the simulator's handshake with Nest is slow, Nest can leak memory at 43 to 90 MB a minute, and the Nest page explains how to see it.

Check it

~/flightsim-on-linux/bin/flightsim-on-linux addon check bbs-757

It prints three lines, each starting with ok or FAIL, and changes nothing, so you can run it with the simulator open:

  • the aircraft package is in Community, with its version, and every file in its layout.json is on disk with the listed size;
  • the same for the liveries package;
  • BBS Nest is installed in the prefix.

A FAIL on a package names the files that are missing or have another size. Reinstall the package with Nest.

Known problems

  • The build of 22 October 2026 draws no weather on the navigation display. That is not a Linux fault: that build's gauge module has the functions for terrain, traffic and the other symbols, and none for weather. The build Nest delivered on 1 November 2026 also reports 0.1.0. Its changelog doesn't mention radar on the navigation display and the test machine hasn't flown it, so this page can't say what it draws.
  • Nest can leak memory through an orphan SimConnect connection, and alone it won't close with the X button. Both are on the Nest page, with the workarounds.
  • The simulator's own memory grows on long flights. After a flight of 4 hours 30 minutes on 27 October 2026, with the 757, the simulator reached 34.2 GB of RAM and 29 GB of swap. At 00:39 on 28 October the system's out-of-memory service (systemd-oomd) ended the simulator's container, with 63.3 of 64.9 GB of RAM and 58.7 of 64.9 GB of compressed swap in use. Nest was part of that, and the simulator grew more than Nest did. The simulator's growth has not been investigated and needs a long measured flight.

Undo

addon undo bbs-757 has nothing to restore, because apply changes nothing. To remove the aircraft, use Nest.
