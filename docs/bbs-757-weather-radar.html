BBS 757 weather radar mod

Tested with the mod's package 1.0.3 on 28 October 2026, on the 757-200 0.1.0. It needs PowerShell 7 and no Wine. touches add-on files: it edits files of the 757 package, and ~/flightsim-on-linux/bin/flightsim-on-linux addon undo bbs-757-weather-radar puts them back from the copy this add-on takes first. The radar has not been seen in flight yet.

Get it

The mod is Temag's, and the download is a zip called B757 Weather Radar Installer 1.0_QqwIl.zip. This page doesn't know the download page. The author's page is buymeacoffee.com/temag33. Inside is a .bat file around PowerShell 5.1 scripts, written for Windows. This project doesn't carry the mod's files, and it never edits them. They are not part of this project.

The stock 757 0.1.0 draws no weather on its navigation displays, which is not a Linux fault. This mod adds a weather radar module.

Install it

You need the aircraft installed by BBS Nest (see the 757 page), PowerShell 7 (the command is pwsh, from your distribution), and the simulator closed. The mod's installer doesn't touch the Wine prefix, so nothing else has to be closed. The CLI still asks for the prefix to be free, because it treats every installer alone, as the ground rules say. Then:

~/flightsim-on-linux/bin/flightsim-on-linux addon install bbs-757-weather-radar ~/Downloads/"B757 Weather Radar Installer 1.0_QqwIl.zip"

Use the name of the file you downloaded. To use a folder you unpacked yourself, run the script directly instead, because the CLI only takes files:

~/flightsim-on-linux/bin/flightsim-on-linux addon launch bbs-757-weather-radar install -- ~/Downloads/radar-bundle

The folder is the one that holds the mod's scripts/Install.ps1. Either way the script does these things in order:

  1. It stops if the simulator runs, if pwsh is missing, or if it finds no scripts/Install.ps1 in what you gave it. A zip is unpacked to a temporary folder, which is deleted at the end.
  2. It backs up the aircraft files the mod edits. The mod makes no backup of its own. The copies go to compatdata/2537590/flightsim-on-linux-backup/bbs-757-weather-radar: the panel folder's panel.cfg and BBS752.wasm, and the package's layout.json. If panel.cfg already holds the radar and there is no backup, the script stops, because the files are no longer the originals: reinstall the aircraft with Nest first. If the radar is already in and a backup exists, it keeps that backup.
  3. It runs the mod's own installer with pwsh, through this add-on's install-weather-radar.ps1.

That launcher is a port of the one the test machine used on 28 October 2026. The mod's Install.ps1 was written for Windows PowerShell 5.1. The launcher reads it and changes it in memory, never on disk: it points the line that loads the mod's Support.ps1 at the mod's folder, replaces two path helpers with versions that use forward slashes, and replaces the call that compiles a JavaScriptSerializer from the .NET Framework with a small class of the same name built on System.Text.Json. It also hands the mod's installer your Community folder and the 757's folder directly. If a new version of the mod's Install.ps1 no longer loads Support.ps1 the way the launcher expects, the launcher stops with that message and nothing has been changed except the backup. With -DryRun added to a direct call of the launcher, the mod's installer only checks.

The mod then adds BBS757WX.wasm to the panel folder, gives the left and right navigation displays a wx_l and a wx_r gauge from it in panel.cfg, and updates layout.json. It refuses a BBS752.wasm it doesn't know. When the mod's installer fails, the script says so and tells you to run addon undo bbs-757-weather-radar.

Make it run

addon apply bbs-757-weather-radar changes nothing and says the install does the work. Then it runs the check.

Start it

There is nothing to start. The radar is a gauge the 757's panel loads. It has not been seen in flight.

Check it

~/flightsim-on-linux/bin/flightsim-on-linux addon check bbs-757-weather-radar

It reads the files and changes nothing, so you can run it with the simulator open. It prints three lines, each starting with ok or FAIL:

  • panel.cfg gives the wx_l and wx_r gauges to BBS757WX.wasm;
  • BBS757WX.wasm is in the panel folder and is not empty;
  • layout.json lists BBS757WX.wasm with the size on disk. The simulator ignores a file the layout doesn't list.

Known problems

  • A BBS Nest update removes the mod. When Nest updates the aircraft, the radar is gone and the check fails. Run the install again. The script first backs up the new originals.
  • A new version of the aircraft may be refused. The mod only patches a BBS752.wasm it knows, so an aircraft version it doesn't cover is refused.
  • It has not been seen in flight. On the test machine it was installed on 28 October 2026 and checked on the files only.

Undo

~/flightsim-on-linux/bin/flightsim-on-linux addon undo bbs-757-weather-radar

Close the simulator first. It copies panel.cfg, BBS752.wasm and layout.json back from the backup, deletes BBS757WX.wasm, and then deletes the backup folder. If the aircraft holds the radar and the backup is gone, it stops and tells you to reinstall the aircraft with Nest, which gives you the originals. If the aircraft has no radar and there is no backup, it says there is nothing to restore.
