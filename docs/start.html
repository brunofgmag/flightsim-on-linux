Start here

This page takes you from a working simulator to the Proton that the hard add-ons need. Most of the time goes into one download and one compile.

  1. Start the simulator once

    Install Microsoft Flight Simulator 2024 from Steam, start it, finish the first setup and quit. Proton creates its Windows folder (the "prefix") on that first start, and the simulator writes where your Community folder lives. The helper app reads both.

    The Microsoft Store and Xbox app versions don't run on Linux, so this site covers only the Steam version.

  2. Install the programs the build needs

    On Arch, CachyOS, EndeavourOS and Manjaro:

    sudo pacman -S --needed git base-devel flex bison perl mingw-w64-gcc zenity

    On other distributions, install the same things under their names there: git, a C compiler with make and autoconf, flex, bison, perl, the MinGW-w64 cross compiler for x86_64, and zenity or kdialog. The setup check in step 4 lists whatever is still missing.

  3. Download this project

    git clone https://github.com/brunofgmag/flightsim-on-linux.git ~/flightsim-on-linux

    Or download the ZIP from the project page and unpack it in your home folder.

  4. Run the setup check

    ~/flightsim-on-linux/bin/flightsim-on-linux-gui

    The first window lists what it found: Steam, the simulator, its prefix, the Proton it uses and your launch options. Lines marked ok are fine. Lines marked WARN or FAIL say what to do next. If you prefer the terminal, bin/flightsim-on-linux doctor prints the same list.

  5. Set the launch option

    In Steam, right-click Microsoft Flight Simulator 2024, choose Properties, and under Launch Options put:

    PROTON_NO_NTSYNC=1 %command%

    The overlay this setup builds on was tested with ntsync off, and with plain Proton-CachyOS the simulator froze in the menu or while loading an aircraft with ntsync on. PROTON_USE_NTSYNC=0 looks similar, but Proton ignores it.

  6. Build Proton Fenix A320

    In the helper app, pick Build Proton Fenix A320. In the terminal it is:

    ~/flightsim-on-linux/bin/flightsim-on-linux proton build

    It downloads Proton-CachyOS (about 350 MB) and the Wine source, applies the patches, compiles 13 Wine modules and installs the result as a new Steam compatibility tool. You need about 3 GB free in your home folder. On a 16-thread CPU the compile took about a minute; slower machines take longer. Your current Proton stays untouched.

  7. Pick it in Steam

    Restart Steam. Right-click the simulator, choose Properties, open Compatibility, and under Select compatibility tool choose Proton Fenix A320 (cachyos-11.0-20261005-slr).

  8. Check it

    Run the helper again and pick Check the Proton the simulator uses, or:

    ~/flightsim-on-linux/bin/flightsim-on-linux proton check

    It creates a throwaway prefix, runs four small test programs and deletes the prefix. You should see All 4 checks passed. Each check names the add-on it protects, so a failure tells you what will break.

Next

Read the ground rules before installing anything. They save a lot of confusion. Then go to the add-on list.

To undo everything: pick another Proton in the simulator's Compatibility tab and delete the Proton-Fenix-A320-… folder from ~/.local/share/Steam/compatibilitytools.d/.
