Aerosoft A340-600 Professional

Tested with the Aerosoft A340-600 Professional 1.0.5 on 15 October 2026. Nothing Linux-specific is needed beyond the store it comes from: the aircraft is an MSFS package that runs inside the simulator.

Get it

The A346 Pro comes from the Aerosoft One store, as the package aerosoft-aircraft-a346-pro. This guide doesn't have the store page, so look in the store. addon install aerosoft-a346-pro only prints where it comes from.

Install it

Install the aircraft with Aerosoft One, as on Windows. Its guide covers the app itself, which is a native Linux program that needs two options on its command line and has to be pointed at the simulator's packages folder. On 14 October 2026 Aerosoft One installed the aircraft into its own library on the test machine and made a link to it in the Community folder.

~/flightsim-on-linux/bin/flightsim-on-linux addon install aerosoft-a346-pro

That command prints the store and the kind of installer, and runs nothing.

Make it run

Nothing. The aircraft needs no Proton FS2024 patch and no setting in the prefix. It was tested on Proton FS2024, and stock Proton was not tried. addon apply aerosoft-a346-pro says there is nothing to apply and then runs the check.

Check it

~/flightsim-on-linux/bin/flightsim-on-linux addon check aerosoft-a346-pro

It prints one line, starting with ok and giving the version, and it changes nothing. A link that resolves counts, because that is how Aerosoft One installs. It prints FAIL when the package isn't in your Community folder, when it is a link to a folder that is gone, or when it has no readable manifest.json.

Known problems

  • Moving the Aerosoft One library removes the aircraft, because the link in Community points into the old place. The check then reports a link to a folder that is gone. Keep the library where Aerosoft One put it.
  • The aircraft flew on the test machine on 15 October 2026, and no problem is open.

Undo

addon undo aerosoft-a346-pro has nothing to restore, because nothing was changed. Remove the aircraft with Aerosoft One.
