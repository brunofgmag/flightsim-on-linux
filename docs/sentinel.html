Simulator sentinel

Tested on 1 November 2026. A 17 KB program called FlightSimulator2024.exe that sleeps. A service keeps it open in the add-ons prefix while the simulator runs.

Why it exists

A program in the add-ons prefix sees the processes of that prefix only, and some programs look for the simulator there:

  • ActiveSkyUtils.exe looks for flightsimulator2024 in the process list every 2 seconds and closes when it isn't there. Without the sentinel it died within seconds. With it, it stayed past 30 seconds.
  • vRAAS starts SimConnect only after it sees that process. Without the sentinel it stopped at Starting API completed. Opening the sentinel moved it on in under 30 seconds.

Axis and Ohs and Volanta don't need it.

Make it run

You need the add-ons prefix and MinGW-w64, as its guide says.

~/flightsim-on-linux/bin/flightsim-on-linux addon apply sentinel
~/flightsim-on-linux/bin/flightsim-on-linux addon watcher sentinel

The first builds the program. The second writes a user service called flightsim-on-linux-sentinel.service and switches it on.

Start it

There is nothing to start. The service looks every 8 seconds and opens the sentinel as soon as the simulator is there. If the sentinel dies with the simulator running, the next look brings it back. When the simulator closes, the service asks it to end with SIGTERM, and ActiveSky Utils then closes by itself.

Check it

~/flightsim-on-linux/bin/flightsim-on-linux addon check sentinel

It prints two lines and changes nothing: the program is built, and it is running. With the simulator closed the second line passes. With the simulator open and no sentinel it fails, and says to switch the service on.

Known problems

  • The sentinel runs from your cache folder, and this project finds the simulator by its Steam path, so nothing here takes one for the other. A search of your own for FlightSimulator2024 finds two processes while the simulator runs.
  • The name is enough for these two programs. A program that wants the simulator's memory gets nothing from it, as the add-ons prefix guide says.

Undo

~/flightsim-on-linux/bin/flightsim-on-linux addon watcher sentinel --off

This takes out the service. addon undo sentinel has nothing to restore: apply only builds a program in the cache.
