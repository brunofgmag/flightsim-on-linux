title: Aerosoft One description: How to use the native Linux Aerosoft One with MSFS 2024: the AppImage options, the packages folder you give it by hand, the check that reads only that one setting, and what the simulator's own folder move does to its links. ---

Aerosoft One

Tested with Aerosoft One 0.16.12 on 14 October 2026. It is a native Linux program, so it doesn't go into the simulator's prefix. It takes two Chromium options and one folder that you choose by hand, and addon apply only reads whether that folder is right.

Get it

Aerosoft publishes Aerosoft One as an AppImage for Linux, 84 MB for this version. Take that one. A Windows Aerosoft One Setup.exe was downloaded beside it on the test machine and never used. Where the AppImage is downloaded from and what Aerosoft One costs aren't recorded here; get it from Aerosoft.

~/flightsim-on-linux/bin/flightsim-on-linux addon install aerosoft-one

This prints where to get it and what kind of program it is. It installs nothing.

Install it

Make the AppImage executable and run it with the two options the test machine used. Why it needs them was not recorded:

chmod +x "Aerosoft One.AppImage"
./"Aerosoft One.AppImage" --no-sandbox --disable-gpu

It doesn't find the simulator by itself. In the app, add MSFS 2024 (Steam) by hand and give it the simulator's packages folder, the one that holds Community. ~/flightsim-on-linux/bin/flightsim-on-linux machine prints it as packages. The check follows links, so a link that leads to that folder passes.

Make it run

~/flightsim-on-linux/bin/flightsim-on-linux addon apply aerosoft-one

This changes nothing. It reads one setting, manuallyDetectedGamesData.msfs2024Steam.directory in ~/.config/Aerosoft One/persistent-store.json, follows links and compares the folder with the packages folder that the CLI found. It prints that folder and nothing else from the file. The file also holds your login token and your e-mail address: never paste it into an issue, a forum post or an AI chat.

Start it

There is no menu entry, because the AppImage can be anywhere on your disk. To make one, point a .desktop file at your copy with the same two options.

Check it

~/flightsim-on-linux/bin/flightsim-on-linux addon check aerosoft-one

It prints one line, starting with ok or FAIL, and changes nothing, so you can run it with the simulator open. It says whether Aerosoft One's MSFS 2024 (Steam) folder is the simulator's packages folder. When it fails, the line names both folders. Add the game again in the app with the right one, or the aircraft land where the simulator doesn't look.

Known problems

  • Moving the packages folder with the simulator's own option discards the links that Aerosoft One keeps in Community. On 16 October 2026 that made three aircraft (the 727-200F, the 727-200RE and the A346 Pro) disappear from the simulator. The fix was to make the links again, pointing into the Aerosoft One library. Afterwards Aerosoft One made the same links in the folder it knows.
  • The two options come from what worked on the test machine. The cause of the need for them is not known.

Undo

addon undo aerosoft-one has nothing to restore, because apply changed nothing.
