title: Start here description: Step-by-step setup of Microsoft Flight Simulator 2024 on Linux for Windows add-ons, with a helper app that checks your machine. ---

Start here

This page takes you from a working simulator to the Proton that the hard add-ons need. Most of the time goes into one download and one compile.

  1. Start the simulator once

    Install Microsoft Flight Simulator 2024 from Steam, start it, finish the first setup and quit. Proton creates its Windows folder (the "prefix") on that first start, and the simulator writes where your Community folder lives. The helper app reads both.

    The Microsoft Store and Xbox app versions don't run on Linux, so this site covers only the Steam version.

  2. Install the programs the build needs

    On Arch, CachyOS, EndeavourOS and Manjaro:

    sudo pacman -S --needed git base-devel flex bison perl mingw-w64-gcc meson ninja glslang wine zenity

    On other distributions, install the same things under their names there: git, a C compiler with make and autoconf, flex, bison, perl, the MinGW-w64 C and C++ cross compilers for x86_64, meson, ninja, glslang, widl and zenity or kdialog. On Arch, widl comes with the wine package. The setup check in step 4 lists whatever is still missing.

  3. Download this project

    git clone https://github.com/brunofgmag/flightsim-on-linux.git ~/flightsim-on-linux

    Or download the ZIP from the project page and unpack it in your home folder.

  4. Run the setup check

    ~/flightsim-on-linux/bin/flightsim-on-linux-gui

    The first window lists what it found: Steam, the simulator, its prefix, the Proton it uses and your launch options. Lines marked ok are fine. Lines marked WARN or FAIL say what to do next. If you prefer the terminal, bin/flightsim-on-linux doctor prints the same list.

  5. Build Proton FS2024

    Close the simulator. In the helper app, pick Build Proton FS2024. In the terminal it is:

    ~/flightsim-on-linux/bin/flightsim-on-linux proton build

    It downloads Proton-CachyOS (about 350 MB) and the Wine source, applies the patches, compiles 20 Wine modules, the d3d12core.dll of vkd3d-proton and the dxgi.dll of DXVK, runs the forty-one checks on the result and installs it as the Steam compatibility tool Proton FS2024. You need about 3 GB free in your home folder. On a 16-thread CPU the compile took about a minute; slower machines take longer. The Proton you use now stays untouched. When you build again later, the new build replaces Proton FS2024 and the one before it stays in ~/.cache/flightsim-on-linux/previous.

  6. Pick it in Steam

    Restart Steam. Right-click the simulator, choose Properties, open Compatibility, and under Select compatibility tool choose Proton FS2024. You only do this once; later builds keep the same name.

  7. Check it

    Run the helper again and pick Check the Proton the simulator uses, or:

    ~/flightsim-on-linux/bin/flightsim-on-linux proton check

    It creates a throwaway prefix, runs thirty-eight small test programs and deletes the prefix. You should see All 41 checks passed. Each check names the add-on it protects, so a failure tells you what will break.

Next

Read the ground rules before installing anything. Installing add-ons has the order of work and the traps that many installers share, and the add-on list has the page of each add-on. Once an add-on runs, Shortcuts and watchers shows how to start it from your application menu or with the simulator. If the simulator itself freezes in the menu or while loading an aircraft, the ground rules have the first thing to try.

To undo everything: pick another Proton in the simulator's Compatibility tab and delete the Proton-FS2024 folder from ~/.local/share/Steam/compatibilitytools.d/.
