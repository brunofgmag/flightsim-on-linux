Windows add-ons for Microsoft Flight Simulator 2024 on Linux

The simulator itself runs fine under Proton. The add-ons are where it gets hard: installers that do nothing, apps that open and close, tray icons that crash the program, displays drawn wrong. This site collects the fixes that got about 40 of them working, and the checks that tell you whether a fix took.

Where this comes from

Every fix here was found and measured on one machine: CachyOS with KDE Plasma on Wayland, an NVIDIA RTX 4080, the Steam version of the simulator, in October 2026. Each guide says what was tested and when. Your distribution, GPU or add-on version may behave differently. When they do, please open an issue with the output of the checks.

What the fixes change

Almost every fix changes the Windows environment the add-on runs in and leaves the add-on alone: a rebuilt Proton, a setting in the Wine prefix, a launch option, a small stand-in for a Windows component that Wine lacks. A few go further and replace or edit a file that belongs to the add-on. Their guides say so at the top, name the file and tell you how to put the original back.

Nothing here asks for a licence key, cracks a protection or shares a paid file. You install each add-on from its own vendor, with your own account.

The foundation

Most of the hard add-ons need one thing first: Proton FS2024, a Proton-CachyOS build with the fenix-a320-linux-patch overlay and more than thirty Wine fixes. This project builds it on your machine from public sources and then tests it in a throwaway prefix.
