title: Add-ons description: Which Windows add-ons for MSFS 2024 work under Proton, what each one needs, and the state of each guide. ---

Add-ons

Everything below worked on the test machine in October 2026. The version is the one tested. The guides come one add-on at a time, rewritten from the notes taken while fixing each one.

touches add-on files marks a fix that edits or replaces a file belonging to the add-on, or that sits close to its licensing. Its guide says exactly what changes and how to undo it.

Aircraft

Fenix A320, A319, A321 (2.4.1)Proton FS2024, .NET Framework 4.8 for the Fenix programs only, and the Fenix Installer run inside gamescope, the only place it gets mouse and keyboard. Without Proton FS2024 the displays leak memory, lose frame rate within minutes and freeze.guide touches add-on files

While the A321 is loaded, one of the simulator's threads keeps a CPU core busy.guide

Ground services, ATC, weather, camera

Add-onWhat it needsGuide
FSDT GSX Pro (4.0.23) touches add-on filesA copy of wine-mono in the prefix with two methods changed, so the FSDT updater accepts its licence library's registration and its watchdog stops killing the engine; plus the official curl.exe. Reinstalling with the universal installer uses up an activation.in progress
ChasePlane (2026.39) and Flow (2026.33)Two small stand-ins for Windows components Wine lacks, a service that starts the in-sim bridge, and a launch option.in progress
SayIntentions.AI (5.6.3)A launcher and a watcher that keep its Community links from being emptied by Wine's rmdir. The desktop window stays grey; use the in-sim EFB.in progress
BeyondATC (1.8.22)Runs and injects traffic. On the test machine, which keeps desktop programs off the main GPU, it drew with software OpenGL.in progress
Active Sky FSProton FS2024, so GDI+ finds its fonts, a Calibri font made from Carlito, and a way to restart its helper after a crash.in progress
REX Atmos CoreIts window stays empty under the Wayland driver. Use it from your browser instead.in progress
vRAAS (1.3.9)Direct3D 9 off, started inside the simulator's container.in progress
FSRealistic+ (1.1.9)Starts from the simulator's exe.xml as on Windows.in progress

Performance, flight tracking, controls, visuals

Add-onWhat it needsGuide
MSFS AutoFPS (0.5.4)Proton FS2024 for "Close to Tray", Direct3D 9 off, started inside the simulator's container. It won't start from exe.xml.in progress
Volanta (1.19.2)Runs in the simulator's prefix, because its connector is a Windows program.in progress
Navigraph Simlink (1.1.41)Its own Wine prefix, so it can start at login and wait in the tray as on Windows. A SimConnect.cfg next to it points it at the simulator's SimConnect TCP port. The default port, 500, needs root on Linux, so the simulator's SimConnect.xml moves it above 1024. The sign-in comes back as a navigraph-traffic-desktop:// link that Linux has to hand to the prefix. Sometimes Simlink stops updating the aircraft's position, for example after you restart the simulator. Restarting Simlink brings it back.in progress
Lorby Axis and Ohs (4.58.2)A timer fix in wine-mono's WindowsBase, without which its scripts stop after a minute, and joystick IDs remapped from Windows.in progress
OpenDeck for Stream Deck (2.14.1)The native Linux app, with converted Stream Deck profiles and three small source patches.in progress
ReShade (6.8)Copied into the simulator folder as dxgi.dll; no launch option.in progress

Doesn't work

SimAtlas (2.0.5) delivers its packages through a Windows file-system filter driver, and Wine doesn't support those yet.
