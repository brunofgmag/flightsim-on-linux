title: Add-ons description: Which Windows add-ons for MSFS 2024 work under Proton, what each one needs, and the guide for each. ---

Add-ons

Each add-on below ran on the test machine in October 2026, at the version shown, unless its guide says otherwise. Its guide says how it was installed, what it needs to run, and what wasn't seen working.

The scripts in this project were generalised from what ran on the test machine, so the dated results in the guides come from that machine's own earlier scripts unless a guide says otherwise. The checks ran there, read-only, and some of them fail there because it still holds the older files. apply, install and undo were tested on throwaway copies, not on a full prefix. The launch scripts, watchers and menu entries passed their tests against a fake simulator and have not been through a real flight yet. Read a guide before you run its commands, and start with Installing add-ons and the ground rules. Shortcuts and watchers covers menu entries and starting programs with the simulator. The add-ons with hard problems need Proton FS2024.

The Steam launch options of the simulator itself have a guide of their own: Launch options.

touches add-on files marks a fix that edits or replaces a file belonging to the add-on, or that sits close to its licensing. Its guide says exactly what changes and how to undo it.

Base pieces

Other add-ons build on these. Each one does one job in the prefix or the simulator folder, and none of them sets anything for a single add-on.

Add-onWhat it needsGuide
.NET Framework 4.8 (4.8)Microsoft's framework and mscoree.dll in the prefix. The installer exits 0 and installs nothing in a Windows 11 prefix, so the command switches the prefix to Windows 7 while it runs. The Fenix, the Maddog and SayIntentions need it.guide
SimConnect over TCP (SimConnect 12.2.0.0)Moves the simulator's SimConnect port above 1024. The add-ons prefix, Simlink and the aircraft watchers need it.guide
Add-ons prefixA second Wine prefix for Active Sky, vRAAS, Axis and Ohs and Volanta, kept up from login so its desktop doesn't fail when the simulator opens.guide
Simulator sentinelA stand-in called FlightSimulator2024.exe for the programs in that prefix that look for the simulator by name.guide

Doesn't work

SimAtlas (2.0.5) delivers its packages only through a Windows file-system filter driver, and Wine can't host one. It stops at "CBFS StartFilter failed".
